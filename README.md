# Somnath's Homepage

Plain HTML/CSS/JavaScript website hosted on GitHub Pages at https://somnathjanamath.github.io/

- All text is in `index.html` (Home, Publications, Teaching, CV, Workshops and Conferences, Contact).
- Colours and layout: `css/style.css`. Menu behaviour: `js/main.js` (no need to edit).
- Photo: `assets/images/profile.jpg`.
- CV: `assets/cv/cv.pdf` plus page pictures `cv-page-1.png` and `cv-page-2.png` (replace all three together).

To update on GitHub: open the file, click the pencil icon, edit, and commit; or use Add file → Upload files.
